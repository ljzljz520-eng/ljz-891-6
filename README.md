# 售后维修授权站

面向品牌售后体系的**维修网点授权查询 + 总部授权管理**系统。

- **维修网点端**：输入「网点编号 + 授权负责人」，查询可维修品牌、授权期限、上级服务商、开通时间。
- **总部后台**：维护授权信息（增删改查、续期）、到期提醒（30 天内 / 已过期）、查询审计日志。
- 零第三方依赖，Node.js 18+ 直接运行；内置初始化演示数据，开箱即可演示成功 / 失败两类查询。

## 快速开始

```bash
npm start
# 或：node src/server.js
```

启动后访问：

| 入口 | 地址 | 说明 |
| --- | --- | --- |
| 网点查询端 | http://localhost:3000/ | 网点人员使用 |
| 总部后台 | http://localhost:3000/admin | 默认密码 `admin123` |

环境变量：

- `PORT`：监听端口，默认 3000
- `ADMIN_PASSWORD`：后台密码（生产环境务必修改）

数据保存在 `data/db.json`（首次启动自动由 `data/seed.json` 复制生成）。
后台提供「恢复演示数据」按钮；也可删除 `data/db.json` 后重启自动重置。

## 功能说明

### 网点查询端（公开）

- 编号 + 负责人双因子核验；负责人姓名去空白后精确匹配。
- 返回：网点名称、负责人、可维修品牌、上级服务商、开通时间、授权起止日期、授权状态。
- 失败场景明确区分：编号不存在 / 负责人不符 / 已过期 / 未生效，并给出下一步操作建议。

### 总部后台（密码登录）

- **统计概览**：网点总数、有效数、30 天内到期数、已过期数。
- **到期提醒**：页面顶部高亮「已过期」「即将到期（≤30天）」清单，支持直接续期。
- **授权维护**：新增 / 编辑 / 删除网点；支持按状态筛选与关键词搜索。
- **续期**：一键弹窗办理，默认在原到期日基础上顺延一年，可自行调整。
- **查询日志**：记录每次查询的时间、输入编号 / 姓名、结果、来源 IP（保留最近 300 条）。
- **恢复演示数据**：一键回到初始 6 个网点的演示状态。

### 授权状态判定规则

以自然日为粒度（`YYYY-MM-DD`，无时区偏移）：

| 状态 | 条件 |
| --- | --- |
| 有效 active | 已到起始日 且 距到期日 > 30 天 |
| 即将到期 expiring | 0 ≤ 距到期日 ≤ 30 天 |
| 已过期 expired | 距到期日 < 0 |
| 未生效 pending | 距授权起始日 > 0 |

## 目录结构

```
src/
  config.js     端口 / 密码 / 文件路径配置
  server.js     HTTP 服务、路由、接口、鉴权
  store.js      JSON 文件持久化与数据访问
  util.js       日期、状态计算、品牌拆分、转义等工具
data/
  seed.json     初始化演示数据（6 个网点）
  db.json       运行时数据（自动生成，已 gitignore）
public/
  index.html    网点查询端
  admin.html    总部后台
  css/style.css 共享样式
  js/           查询页与后台页前端脚本
```

## 说明

- 后台登录为演示级内存 Token（重启服务需重新登录），未引入数据库与用户体系；
  生产使用请替换为正式鉴权、HTTPS，并通过 `ADMIN_PASSWORD` 设置强密码。
