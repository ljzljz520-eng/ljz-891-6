# 🔧 售后维修授权站系统

面向售后维修网点的**授权信息查询**与总部侧**授权维护、到期提醒**的一体化演示系统。
零第三方依赖，基于 Node.js 内置 `http` 模块 + 原生前端，`npm install` 都不需要。

## 快速开始

```bash
npm run seed     # 1. 写入初始化演示数据（日期相对运行日动态生成）
npm start        # 2. 启动服务（默认端口 3000）
```

- 网点查询页：http://localhost:3000/
- 总部后台：  http://localhost:3000/admin

## 功能说明

### 网点端（维修网点使用）
输入 **网点编号 + 授权负责人** 双因子核验，查询：
- 可维修品牌
- 授权期限（开始 / 到期、剩余天数）
- 上级服务商
- 开通时间、地址、电话等备案信息

### 总部后台
- 授权档案的新增 / 编辑 / 删除 / 停用
- 多品牌维护（顿号、逗号、空格分隔均可）
- 授权**一键续期 1 年**（取当前到期日与今天中较晚者顺延）
- 首页状态统计（有效 / 即将到期 / 已到期 / 停用），点击卡片快速过滤
- **到期提醒**：自动汇总 30 天内到期与已过期网点，按到期日升序排列
- 关键字、品牌、状态多维筛选

### 状态规则（系统实时计算，无需手工标记）
| 状态 | 规则 |
| --- | --- |
| 授权有效 | 未停用且到期日距今 > 30 天 |
| 即将到期 | 未停用且到期日距今 0～30 天 |
| 已到期 | 到期日早于今天 |
| 已停用 | 手工标记暂停 / 注销（即使未到期） |

## 目录结构

```
server/index.js   HTTP 服务 + API 路由
server/store.js   数据层 + 状态/日期纯函数
scripts/seed.js   初始化演示数据
data/stations.json 运行时数据（seed 后生成）
public/           网点查询页 / 总部后台页面
```

## 主要 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/query` | 网点授权查询 `{code, manager}` |
| GET | `/api/dashboard` | 统计 + 到期提醒 |
| GET | `/api/stations?q=&brand=&status=` | 授权列表 |
| POST | `/api/stations` | 新增授权 |
| PUT | `/api/stations/:id` | 更新授权 |
| DELETE | `/api/stations/:id` | 删除授权 |
| POST | `/api/stations/renew` | 续期 `{id, months}` |
